# 🏟️ BetArena - The Ultimate Betting Arena

BetArena is a complete Telegram betting bot with sports betting, crypto integration, and live odds.

## ✨ Features

- ⚽ **Live Sports Betting** - Premier League, La Liga, NBA, and more
- 💎 **Crypto Integration** - BTC, ETH, SOL, USDT support
- 📊 **Live Odds** - Real-time odds from multiple bookmakers
- 🏆 **Leaderboard** - Compete with other players
- 💰 **Virtual Wallet** - Track your balance and bets
- 📈 **Bet History** - View all your past bets
- 🔐 **Secure** - Provably fair betting system

## 📋 Commands

- `/start` - Main menu
- `/cancel` - Cancel current operation

## 🚀 Quick Start

1. Create bot with @BotFather
2. Clone repository
3. Add BOT_TOKEN to Railway
4. Deploy!

## 🔧 Tech Stack

- Python 3.11
- python-telegram-bot 20.8
- SQLAlchemy (Database)
- The Odds API (Live odds)
